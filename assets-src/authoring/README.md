# Production anatomy asset contract

The runtime now supports artist-authored endpoint sculpts for every visible
genetic trait. Procedural muscle displacement is only a fallback while those
assets are absent.

## Cage rules

1. Run `npm run sculpt:export` to create `neutral-cage.obj`.
2. Import it with vertex order preserved. Keep the 13,380 vertices and topology
   unchanged; subdivision may be used for preview but must not be applied.
3. Sculpt silhouette, muscle planes, tendon gaps, and negative separation. Do
   not merely inflate the named muscle. An insertion endpoint must change where
   the belly terminates and where exposed tendon/flat fascia begins.
4. Export each endpoint as OBJ with vertex order preserved.
5. Convert it with `npm run sculpt:import -- <slider> <0|1> <file.obj>` and run
   `npm run bake`.

The endpoint names are defined in `tools/corrective-contract.mjs`. A complete
production set contains fourteen sculpts: two each for biceps insertion, biceps
shape, lat insertion, pec attachment, ab intersections, calf insertion, and
trap height.

## Art-direction acceptance tests

- In a flat clay render, each endpoint must be identifiable without UI labels.
- Lat insertion changes the inferior border and tendon/fascia gap, not only
  width. The low endpoint sweeps toward the iliac crest; the high endpoint
  terminates above it and exposes a visibly flatter lumbar interval.
- Muscle separation is carried by plane changes and negative space. Painted
  lines, normal-map-only grooves, and isolated spherical bulges do not pass.
- The neutral, both endpoints, and intermediate blends must keep the same body
  volume closely enough that the slider reads as anatomy rather than growth.
- Endpoints must be reviewed in relaxed, front double-biceps, rear double-
  biceps, front lat-spread, and rear lat-spread poses before acceptance.

Pose-space shoulder, elbow, hip, and knee correctives are the next asset layer.
They must be authored against the same topology after the trait endpoints are
approved; otherwise pose fixes can hide incorrect anatomy and have to be redone.

## Checked-in authored anatomy

`latInsertion-0.target` and `latInsertion-1.target` are the first completed
endpoint pair. Their muscle outline begins with the Z-Anatomy latissimus meshes;
`tools/author-lat-correctives.mjs` then authors the high-insertion lumbar gap and
the low-insertion sweep as different inferior borders rather than two scale
values on one bulge.

`anatomy-back.target` is a global, leanness-dependent posterior relief. It is
generated by `tools/author-back-anatomy.mjs` from separately normalised atlas
fields for the lats, trapezius, rhomboids, and teres, plus the paired erector
columns. The runtime blends it down as body fat rises.
